دار الأثاث لغرف النوم - النسخة النهائية

التصميم والألوان وصور المنتجات كما هي بدون أي تغيير.

الهيكل:
- index.html            الصفحة الرئيسية (كروت الغرف مكتوبة داخل الـHTML مباشرة).
- room_01.html ... room_19.html   صفحة ثابتة لكل غرفة (عنوان + وصف + canonical + OG + Schema خاصة بها).
- product.html          صفحة تحويل قديمة: product.html?id=room_01 تحوّل تلقائياً إلى room_01.html.
- assets/rooms/room_XX/ فولدر كل غرفة:
    photo_1.jpg, photo_2.jpg ... = صور القطع منفصلة (مقصوصة من الكولاج الأصلي) وهي اللي بتظهر في المعرض.
    original.jpg = الكولاج الأصلي (محفوظ كما هو، غير مستخدم في الموقع).
    ai-cover.jpg = مكان صورة الـAI مستقبلاً (غير مستخدمة حالياً).
- tools/build.py        (اختياري) يولّد كل الصفحات والـsitemap من قائمة الغرف.

لتعديل اسم/وصف غرفة أو رقم الواتساب أو إضافة صور:
1) افتح tools/build.py وعدّل القائمة ROOMS أو WHATSAPP_NUMBER.
   - لإضافة صور لغرفة: حط الصور في فولدرها بأسماء photo_5.jpg, photo_6.jpg ... وتظهر تلقائياً.
   - لتغيير صورة الغلاف: عدّل رقمها في القائمة COVERS.
2) شغّل:  python3 tools/build.py   (يحتاج Python و Pillow)
بدون Python: عدّل ملف room_XX.html و index.html يدوياً.

رسالة الواتساب في كل غرفة تحتوي اسم الغرفة ورابطها.
لا توجد أسعار في الموقع.
